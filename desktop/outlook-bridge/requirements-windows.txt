#   py -3.13 -m venv %LOCALAPPDATA%\SUVDeals\OutlookBridge\venv
#   %LOCALAPPDATA%\SUVDeals\OutlookBridge\venv\Scripts\pip install -r requirements-windows.txt
#   %LOCALAPPDATA%\SUVDeals\OutlookBridge\venv\Scripts\pip install --no-deps <repository root>
#
# The last step installs only the pure shared domain package ``suv_deals`` (no server

# needs Supabase, PostgreSQL or any database driver.
#

# resolves for win32). pywin32 is Windows-only and imported lazily; re-verify it at activation.
